Features

Everything you need to gate a script

Stop key sharing without shipping your source to everyone who asks.

HWID locking

Each key binds to the first device that uses it. Anyone else who tries the key is turned away.

Bulk key generation

Create up to 500 keys at once, with an optional note and expiry. Copy or download them as a file.

Timed or lifetime

Sell 1-day, 30-day, or lifetime access. Expired keys stop working on their own.

Instant revocation

Ban a key, reset its HWID, or delete it. The change applies the next time the user runs the loader.

Multiple projects

Run several scripts from one dashboard. Each project has its own keys, script, and loader URL.

Rate limited

The auth and login endpoints are rate limited, so guessing keys or the admin password doesn't scale.

How it works

Live in three steps

  1. 1

    Create a project

    Name it in the dashboard and paste in the Lua you want to protect. It stays on your server.

  2. 2

    Hand out keys

    Generate keys and give each buyer one, along with your project's two-line loader.

  3. 3

    Users run the loader

    The loader sends the key and HWID. If both check out, your script comes back and runs.

Developers

A plain JSON API

The loader is one POST request. You can call the same endpoint from your own UI, key checker, or bot.

  • invalid_keyKey doesn't exist for this project
  • hwid_mismatchKey is bound to another device
  • key_expiredKey is past its expiry date
  • key_bannedKey was banned from the dashboard
  • rate_limitedToo many attempts, try again shortly
